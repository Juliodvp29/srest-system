Manual de Usuario

Guía completa para dominar todas las funciones de tu sistema de restaurante. Desde la toma de pedidos hasta el análisis de ventas.

login

1. Acceso al Sistema

Para ingresar al sistema, utiliza tus credenciales institucionales. Es fundamental mantener tu contraseña segura y no compartirla.

priority_high

Importante: Cada acción realizada queda registrada con tu usuario para fines de auditoría y seguridad.

point_of_sale

2. Punto de Venta (POS)

Tomar un Pedido

  1. Paso 1

    Selecciona una mesa disponible (color verde) en el mapa de salón.

  2. Paso 2

    Navega por las categorías y agrega los platos solicitados por el cliente.

  3. Paso 3

    Configura modificadores si es necesario (términos de carne, salsas, etc).

  4. Paso 4

    Pulsa "Enviar a Cocina" para procesar la orden inmediatamente.

Dividir Cuenta

¿Varios clientes en la misma mesa? Usa la opción de **Split Bill** para mover ítems a cuentas separadas y cobrar a cada uno su consumo exacto.

skillet

3. Gestión de Cocina

Diseñado para el personal de producción. Los pedidos aparecen automáticamente en tiempo real.

timer

Control de Tiempo

Observa cuánto tiempo lleva cada plato en preparación para priorizar pedidos urgentes.

check_circle

Estados de Orden

Marca como "Listo" para notificar al mesero que el pedido puede ser servido.

event_available

4. Reservaciones

Administra las visitas futuras de tus clientes con facilidad.

  • add Registra nombre, teléfono, fecha, hora y número de comensales.
  • table_restaurant Asigna una mesa específica para asegurar la disponibilidad.
  • update Cambia el estado de la reserva (Confirmada, Cancelada, Finalizada).
inventory

5. Inventario y Stock

Escandallos (Recetas)

El sistema descuenta automáticamente los insumos al vender un producto si tienes configurada su receta correctamente.

Alertas de Bajo Stock

Recibe notificaciones automáticas cuando tus insumos críticos estén por agotarse.

settings

6. Administración

Módulos de configuración global del restaurante, accesibles principalmente para Gerentes y Administradores.

Productos y Categorías

Crea tu menú digital, define precios, imágenes y organiza todo por categorías lógicas.

Personal y Roles

Gestiona a tus empleados y asigna permisos específicos según su función (Mesero, Chef, etc).

Configuración de Sucursal

Edita los datos que aparecen en tus tickets: nombre legal, dirección y teléfono.

Mesas

Define el número de mesas y su disposición física para el mapa del salón.

analytics

7. Reportes

Analiza la salud de tu negocio con datos precisos generados automáticamente.

trending_up Ventas: Ingresos totales y flujo de caja diario.
restaurant Productos: Los platos más rentables y más vendidos.
groups Personal: Desempeño y ventas por mesero.
